# C044 — VLQ exotic decays to S/ALP (Gate 4, experimental status review)

Reviewer role: skeptical experimentalist. Sources: INSPIRE (tools/inspire.py), full-text PDFs (tools/arxiv_pdf.py), CMS public results page for CMS-PAS-B2G-24-005. Date: 2026-10-05.

## Bottom line
- **Sub-target (1), T T -> (t S0)(t S0) -> 6t (S0 -> t tbar)**: **partly open**. No dedicated search was found. The recasting atlas arXiv:2609.00127 (Sec. on Fig. 4a) states that "no direct search is available yet" and that a recast excludes masses up to 1.65 TeV at BR = 100%. That recast is driven by existing SS2L/3L searches (CMS TOP-18-003 SR8, ATLAS 1909.08457 Rpv2L, ATLAS 1706.03731; listed in Table/Fig. 13 of 2609.00127). The final state is therefore indirectly covered. The open piece is a dedicated multi-lepton, high-N_b, high-S_T analysis optimised for 6t.
  - The mixed mode in which one S decays to gamma gamma and the other to t tbar is directly covered by ATLAS arXiv:2607.28381, which includes a gamma gamma + t tbar channel.
- **Sub-target (2), X5/3 -> t phi+ -> t W+ gamma (SS dilepton + hard photon)**: **open (proposed-not-searched)**. No CMS or ATLAS search with SS leptons plus a photon from a VLQ was found.
  - CMS-PAS-B2G-24-005 (INSPIRE 3157006) covers only X5/3 -> tW and X5/3 -> tH+ with H+ -> tb, in the single-lepton channel.
  - The older SS-dilepton X5/3 searches (CMS 1810.03188, ATLAS 1807.11883) assume tW only.
  - Recasts of SSL searches (1907.05894) already constrain the channel "at the same level as the standard one" (abstract). The gain would be incremental, not a new reach.
- **Sub-target (3), T -> t S with S -> gg/WW, and B -> b Phi (gg/bb) with Phi != 125 GeV**: **partly open / indirectly covered**.
  - **T -> t phi, phi -> bb:** directly covered in single production (CMS 2510.25874, m_phi 25–250 GeV; CMS 2604.10729, m_phi 75–500 GeV).
  - **T T -> t phi, phi -> gamma gamma:** directly covered in pair production (CMS 2610.03489; ATLAS 2607.28381).
  - **S -> WW in pair production:** covered only if the other S decays to gamma gamma (ATLAS 2607.28381 gamma gamma WW channel).
  - **No VLQ-interpreted search found for:**
    - pair-produced T -> t S with S -> gg or S -> bb at arbitrary m_S;
    - B -> b Phi with m_Phi != m_H.
  - **Final-state neighbours without a VLQ interpretation:**
    - CMS stealth/RPV top-squark searches (2102.06976; 2506.08825: >=6 jets, 0/1/2 leptons, tt + 6 light partons);
    - CMS pair-produced multijet/trijet resonances (1810.10092, 2404.02992);
    - CMS B -> bH fully hadronic (2402.13808).
  - This is a reinterpretation-first gap.
- **Overall status label: `searched-limited-regime` / `indirectly-covered`.** Confidence that a genuinely open, HL-relevant experimental target exists: **medium** for (1) and (2), **low–medium** for (3).

## Open region (precise)
1. **Dedicated TT -> (tS0)(tS0) -> 6t search.** Final state: SS2L/3L/4L, >=4–6 b-tags, very high S_T. This is the S0 -> t tbar regime (m_S0 > 2 m_t). The only direct coverage is the gamma gamma + t tbar mixed channel of ATLAS 2607.28381. The 2SSL/3L searches cover it indirectly via the 1.65 TeV recast. HL-LHC value: a dedicated search is claimed to extend beyond 1.5 TeV (2609.00127). This claim is pheno and UNVERIFIED by any experiment.
2. **X5/3 -> t phi+ -> t W+ gamma.** Final state: SS dileptons + hard photon + b-jets, with a W gamma resonance. No search found. Both W gamma resonance searches found (CMS 2106.10509, ATLAS 2304.11962) are for inclusive single resonances only.
3. **Pair-produced T -> t S with S -> gg (below the t tbar threshold) or S -> bb.** Also B -> b Phi with m_Phi != 125 GeV.
   - No VLQ interpretation was found.
   - Final-state coverage exists in stealth/RPV searches, so these are a recast target first.
   - 1908.07524 states that this scenario weakens T bounds, allowing m_T as low as 400 GeV (abstract).
4. **Long-lived S from VLQ decays.** No VLQ + LLP search was found; the only VLQ/LLP hits concern vector-like leptons (CMS 2503.16699). Not verified in depth.

## HL-LHC / Phase-2 projection documents
- CMS HL-LHC projection, T -> bW/tZ/tH single lepton (INSPIRE 2611744 / 2809474): projected exclusion of m_T < 1750 GeV with 3 ab-1. Standard decays only.
- ATLAS PUB (INSPIRE 3071495): single-T -> W(l nu) b plus vector-LQ HL-LHC projections. Standard decays only.
- No experimental HL-LHC projection was found for any VLQ -> t/b + new scalar channel.

## Key caveats
- These "first search" claims come from the collaborations' own wording (CMS 2610.03489, ATLAS 2607.28381). Absence of the 6t and SSL+gamma searches comes from INSPIRE queries and is not proof of absence. Run-3 VLQ searches (13.6 TeV) returned nothing in INSPIRE. CMS/ATLAS internal work in preparation is unknowable.
- Sub-target (1) has a real cost: a dedicated 6t search competes with the SM 4-top background and with existing SS2L/3L BSM searches that already set strong recast limits. The incremental reach is pheno-claimed only.
- Branching ratios to S are model-dependent. Both the CMS and ATLAS diphoton searches already cover the composite-Higgs benchmark when BR(S -> gamma gamma) is non-negligible.
- The X5/3 tW exclusion number came from WebFetch of the CMS page and should be re-checked against the PAS PDF.
