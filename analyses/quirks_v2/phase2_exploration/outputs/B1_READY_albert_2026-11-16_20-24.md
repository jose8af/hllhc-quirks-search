## 3. What a B1 event file holds (schema; one compressed npz per job + `<job>.npz.sha.json`)

- `hits` / `hit_off` (run_chain.COLS: sid, x, y, z, s0, s1, flag, vp, particle, gen, vsec, dE, t): every measurement
  on the barrel counting surfaces and the BTL. No pile-up: all are own hits; `flag` bit 0 = on a selected CKF track,
  so the record is "own hits before CKF" with the after-CKF subset marked (Df-9). Truth attribution per hit: `vsec`
  0 = parent, ≥ 1 = product (1 at the Geant4 vertex, ≥ 2 later decay points), `particle` = input row, `gen` ≥ 1 =
  made by Fatras. `tru` truth position of each hit; `toy` / `toy_off` SimHits on every surface; `v41`, `timing`.
- `evt` (30 columns, `meta['evt_cols']`): vertex index, PV draw, `phimet` (independent uniform draw), numbers of
  Geant4 products / handed-over rows / dropped parent hits, parent charged flag, **class code**, **parent pdg, p_T, η,
  φ at the origin**, **`road_dphi` and `phi_road`** (true offset to the event's own MET axis for hs / offroad; a
  stored U(−0.15, 0.15) draw otherwise), **vertex radius, z, time, layer (volume code)**, first-arc flag, parent
  momentum at the vertex, firing index, **pool file / row / source event and source weight `w_src`**, event seed.
- `gvtx` (the Geant4 vertex row), `gprod` / `gprod_off` (Geant4 products at the slab exit), **`gcross` / `gcross_off`
  (Geant4 crossings of the parent before the vertex: surface, position, time, momentum)**, `inj` / `inj_off` (rows
  given to Fatras).
- **`ev_mode`** per event (−1 neutral parent, 0 radius cut, 3 hybrid = time cut + Geant4 crossings), **`n_parent_inj`**
  (parent hits added from Geant4), **`n_early_prod`** (product hits before their own production time).
- `meta`: sample, class list and codes, counts per class and per `ev_mode`, **stream, chunk, job seed** of the job and
  of its vertex file (`vertex_file_meta`: stream, chunk, seed, pass, firings, pool files with their streams and
  hashes, pool window, draw, distinct parents, firings per parent), vertex file path and sha256, **`trunc_mode`,
  `seam_window_ns`**, `beta_min`, `road_orientations` (n = 21, axes φ_road + 2πk/21: recorded, nothing simulated per
  orientation), column names, surface and process names, sha256 of every script and chain file, `content_sha256`.
- Vertex files (`pilot.g4`): `vtx`, `cls`, `src`, `prod`, `cross` per class group; meta holds the full partition
  table of the job (class × species, conversions and "other" included; the sum is asserted against Geant4's count).
- Pool files (`pilot.c0.hs.pool`): `pool_{int,pdg,pt,eta,phi,dphi,w}`, `evt` (source file, event, chunk, w_v1,
  φ_MET, seeds).
