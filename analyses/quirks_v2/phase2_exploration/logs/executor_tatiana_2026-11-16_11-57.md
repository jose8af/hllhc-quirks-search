## 4. What is recorded per pilot event (full hit records, STR §4.4 pt 5)
- `ev<i>` (n, 13): every measurement on the barrel counting surfaces and the BTL (`run_chain.COLS`: sid, x, y, z, s0, s1,
  flag bit0 = on a selected CKF track, vp, particle, gen, vsec, dE, t); `tru<i>` truth positions; `vz<i>` vertices;
  `v41` ingestion closure; `timing`; `meta` (seeds, stream, chunk, code sha256, versions).
  With no pile-up every written hit is an own hit of the term; the CKF flag is stored so that the classification on
  **all own hits before CKF** (Df-9) and any after-CKF comparison are both possible from the same record.
- B1 events also: the Geant4 vertex record (process, volume, parent PDG and momentum at the vertex, position, time,
  every product), the parent's Geant4 crossings of the sensitive surfaces, the parent's origin vertex.
- Z(νν) events also: truth neutrino MET vector, generator tries, σ_gen, generator-level jets (SlowJet anti-kT 0.4,
  pT > 20 GeV), prompt isolated e/μ/γ candidates, and the v1 generator-level preselection weight of `gen_d123.presel`
  (as a labelled v1 quantity; the v2 MET model is applied in Phase 3 from the stored summary).
- Not recorded: any per-rung flag or count. The pilot is classified in Phase 3 (channel (i)); I compute no H.

## 5. Open choices found while reading (none is taken silently; options and recommendation; reported to the orchestrator)
- **O1 population of the "unbiased" DIF and NI events.** STR fixes 10⁶ events per term and N_t (Table 4.4a: 6.51×10⁷ for
  DIF = N_trig × 1.59); rule 1 reads one DIF pilot count as N_t/M = 65 events. The v1 rate 1.59 is defined on a phase
  space [V: `gen_d123.py` l.141-169]: prompt π±/K±, 0.5 < pT < 10 GeV, |η| < 1, |Δφ(particle, road)| < 0.15, decay at
  30 < r < 1000 mm; NI: π±/K±/p, 0.5 < pT < 20 GeV, |η| < 1, in the road, × cosh η × x/λ_I. STR does not say which
  population the pilot samples. (a) the v1 rate phase space with the natural Pythia spectrum inside it (the only
  reading for which N_t/M = 65 holds); (b) every hadron Fatras accepts (pT > 50 MeV, |η| < 4, any φ), N_t recomputed
  (orders of magnitude larger; the m = 0 floor at 10⁶ events then exceeds 300 by itself). Recommendation: (a).
- **O2 hard-scatter share.** rate_t = HS + 200 × min-bias; the HS share is ≈ 1–2 % of the DIF rate
  [V: STR §2, per-process spread 1.5687–1.5945] but has a harder spectrum. (a) pilot from minimum-bias primaries only;
  (b) natural mixture with primaries from Z(νν) hard scatters. Recommendation: (a) for day 5, (b) as an addition in
  Phase 3 if wanted (needs the v2 preselection).
- **O3 NI "PV-line factor" 0.22.** N_t of the NI terms contains v1's 0.22 (STR §4.4 pt 6). A Geant4 vertex is on the
  parent's trajectory by construction, so the factor has no counterpart in generation. (a) generate without it and
  read one NI pilot count as N_trig × rate (4.0 / 5.1 / 5.1 events, not 0.88 / 1.12 / 1.12); (b) keep 0.22 in N_t.
  Recommendation: (a), decided by the orchestrator because it changes a number of rule 1.
- **O4 NI radii with real geometry.** Geant4 gives inelastic vertices in every layer; STR has terms at 22, 30, 61.5 mm
  only. I record every vertex with its volume; the pilot samples take beam pipe, TBPX L1, TBPX L2. The rate in the other
  layers is reported (strategy-revision input if not small).
- **O5 Z(νν) pilot and the preselection.** Rule 1 reads one Z(νν) count as N_trig/2.3×10⁶ = 10.9 events, i.e. it
  assumes 2.3×10⁶ *preselected* events. The generator yields events passing truth MET > 200 GeV; v1 then weights by the
  preselection (N_trig/(σ L K) ≈ 0.41 [E from STR numbers 2.51×10⁷/(14.6 pb × 3 ab⁻¹ × 1.4)]). (a) 2.3×10⁶ filter-level
  events (the budgeted 29 CPU-h; effective size ≈ 0.41 × 2.3×10⁶, one count ≈ 27 events); (b) generate until 2.3×10⁶
  pass the v1 generator-level preselection (≈ ×2.4 cost). The timing job measures the fraction. Reported before submitting.
- **O6 DIF decay region and vertex per event.** One Geant4 vertex per event (STR "each with its Geant4 vertex"); decays
  at 30 < r < 1000 mm as in the rate (follows O1 (a)); a primary whose first vertex is of another type is not a DIF
  event.
- **O7 hand-over variant in the pilot.** STR compares two variants on 100 events in Phase 3 and freezes one, and the
  pilot is re-classified "with the frozen variant" by day 12. Recommendation: simulate variant A (Fatras parent,
  `Truncate`, v1 code path) and store the Geant4 parent crossings in the same record, so variant B can be built at

- **O8 road and PV.** Not fixed at generation: the record keeps the particle origin, an independent luminous-region PV
  draw and a road draw; any orientation or PV convention can be applied in Phase 3 (STR §2 own-z placement, §4.4 pt 5

- **O9 B2 Phase-2 part.** The brief gives channel (i) the day-0 ρ = 2 memory and storage measurement and channel (iii)
