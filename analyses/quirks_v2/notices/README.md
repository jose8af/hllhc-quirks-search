# Notices to the user — quirks v2

A new file here means something needs your attention. File names sort by time: `<date_time>_<KIND>_<subject>.md`.

| Kind | Meaning |
|---|---|
| `DECISION` | a decision of yours is needed; options, recommendation and deadline are inside |
| `PROBLEM` | a cluster fault needing you or an admin, or a stop rule fired |
| `RESULT` | a result that changes the outlook, a decision point or gate reached, or a failed criterion |
| `INFO` | context that does not need action |

Routine progress is in the daily reports (`../daily/`, LaTeX + PDF) and the current state in `../STATUS.md`.
